# Kenya Dating Connect

Location-based online dating platform for people in Kenya to connect, match, and chat.

## Features
- User registration/login (Netlify Identity)
- Profile setup with photos, bio, interests
- Location-based matching (GPS)
- Swipe, like, match
- Real-time chat
- Filters: county, distance, age, tribe, religion, etc.
- Safety/report system
- Premium features (M-Pesa)

## Tech Stack
- Frontend: Next.js
- Backend: Netlify Functions
- Database: Netlify Database (Postgres)
- Auth: Netlify Identity
- Hosting: Netlify + GitHub

## Getting Started
1. Clone the repo
2. `npm install`
3. `netlify dev` or deploy to Netlify

Localized for Kenya: counties, Sheng, M-Pesa, etc.
